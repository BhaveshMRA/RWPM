151## Anti-Patterns (What NOT to Do)
152 
153### Navigation
154- ❌ Vertical sidebar navigation
155- ❌ Square/rectangular tabs
156- ❌ Dropdown-only navigation
157 
158### Cards
159- ❌ Sharp corners (`rounded-none`, `rounded-sm`)
160- ❌ Heavy shadows (`shadow-lg`, `shadow-xl`)
161- ❌ Raw `<h3>` tags in `Card.Header`
162 
163### Buttons
164- ❌ Square buttons (`rounded-none`, `rounded-md`)
165- ❌ Hardcoded colours (`bg-blue-500`)
166- ❌ Missing hover states
167 
168### Colours
169- ❌ Hardcoded hex values in components
170- ❌ `text-white` outside image overlays
171- ❌ Inconsistent opacity values
172 
173### Spacing
174- ❌ `space-y-*` utilities
175- ❌ `mt-*` for sibling spacing
176- ❌ Odd gap values (`gap-3`, `gap-5`, `gap-7`)
