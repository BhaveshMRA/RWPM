47## Rules
48 
49- **Privacy redaction always.** Even for local backup.
50- **Verify hash post-transfer.** Silent corruption is real.
51- **Retry transient.** Network blips ≠ failure.
52- **Ledger every sync.** Audit trail.
53 
54## Anti-patterns
55 
56- Skipping redaction "for speed"
57- Ignoring hash mismatch
58- Re-syncing without delta detection
59- Cloud creds in command line (use env vars / managed creds)
60 
61## When NOT to use
62 
63- Memory store empty — nothing to sync
64- Pre-setup — `/siftcoder:onboard` first
