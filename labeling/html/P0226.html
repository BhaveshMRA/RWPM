216## SLIs, SLOs & Error Budgets
217 
218```
219SLI (Service Level Indicator) → What you measure
220  "99.2% of requests complete in <500ms"
221 
222SLO (Service Level Objective) → Your target
223  "99.9% of requests should complete in <500ms"
224 
225SLA (Service Level Agreement) → Your contract (with penalties)
226  "99.95% uptime or we refund 10%"
227 
228Error Budget = 100% - SLO
229  SLO: 99.9% → Error budget: 0.1% → 43 min downtime/month
230  SLO: 99.5% → Error budget: 0.5% → 3.6 hours downtime/month
231 
232Rules:
233- Burn error budget too fast → freeze deployments
234- Error budget remaining → ship features faster
235- Don't set SLOs you can't measure
236- SLOs should be slightly below actual performance
237```
