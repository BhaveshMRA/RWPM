66### 1. Accessibility (CRITICAL)
67 
68- `color-contrast` - Minimum 4.5:1 ratio for normal text (large text 3:1
>); Material Design 
69- `focus-states` - Visible focus rings on interactive elements (2–4px; A
>pple HIG, MD) 
70- `alt-text` - Descriptive alt text for meaningful images
71- `aria-labels` - aria-label for icon-only buttons; accessibilityLabel i
>n native (Apple HIG) 
72- `keyboard-nav` - Tab order matches visual order; full keyboard support
> (Apple HIG) 
73- `form-labels` - Use label with for attribute
74- `skip-links` - Skip to main content for keyboard users
75- `heading-hierarchy` - Sequential h1→h6, no level skip
76- `color-not-only` - Don't convey info by color alone (add icon/text)
77- `dynamic-type` - Support system text scaling; avoid truncation as text
> grows (Apple Dynamic Type, MD) 
78- `reduced-motion` - Respect prefers-reduced-motion; reduce/disable anim
>ations when requested (Apple Reduced Motion API, MD) 
79- `voiceover-sr` - Meaningful accessibilityLabel/accessibilityHint; logi
>cal reading order for VoiceOver/screen readers (Apple HIG, MD) 
80- `escape-routes` - Provide cancel/back in modals and multi-step flows (
>Apple HIG) 
81- `keyboard-shortcuts` - Preserve system and a11y shortcuts; offer keybo
>ard alternatives for drag-and-drop (Apple HIG)

104

>xt (FOIT); reserve space to reduce layout shift (MD)

>ute-level splitting

122- `offline-support` - Provide offline state messaging and basic fallback
