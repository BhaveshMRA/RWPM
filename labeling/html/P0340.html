112## PersistenceManager — Quick Start
113 
114Inject via qualifier and execute manual Cypher:
115 
116```kotlin
117@Component
118class PersonRepository @Autowired constructor(
119    @Qualifier("neoManager") val manager: PersistenceManager
120) {
121    @Transactional
122    fun findByCity(city: String): List<Person> {
123        return manager.query(
124            QuerySpecification
125                .withStatement("MATCH (p:Person {city: \$city}) RETURN p
 >roperties(p)")
126                .bind(mapOf("city" to city))
127                .transform(Person::class.java)
128        )
129    }
130}
131```
132 
133**Key rules:**
134- Always wrap multiple RETURN values in a single map: `RETURN { name: a.
 >name, age: a.age } AS result`
135- Use `@Transactional` for write operations
136- See `references/persistence-manager.md` for batch operations, transact
 >ion management, and custom result transformation

159 
160```kotlin

 >r, or upgrade Kotlin |
203| Dirty tracking on detached objects | Load within the same manager cont
 >ext before saving |

 >ionship(cascade = ...)` — the other annotation does not work |
