284## Best Practices
285 
286- **Use GENCODE IDs** (e.g., `ENSG00000130203.10`) for gene queries; the
 > `.version` suffix matters for some endpoints
287- **GTEx variant IDs** use the format `chr{chrom}_{pos}_{ref}_{alt}_b38`
 > (GRCh38) — different from rs IDs
288- **Handle pagination**: Large queries (e.g., all eGenes) require iterat
 >ing through pages
289- **Tissue nomenclature**: Use `tissueSiteDetailId` (e.g., `Whole_Blood`
 >) not display names for API calls
290- **FDR correction**: GTEx uses FDR < 0.05 (q-value) as the significance
 > threshold for eQTLs
291- **Effect alleles**: The `slope` field is the effect of the alternative
 > allele; positive = higher expression with alt allele
