24## Quick Start

26### New Component Checklist
27 
28Creating a component? Follow this checklist:
29 
30- [ ] Use `React.FC<Props>` pattern with TypeScript
31- [ ] Lazy load if heavy component: `React.lazy(() => import())`
32- [ ] Wrap in `<SuspenseLoader>` for loading states
33- [ ] Use `useSuspenseQuery` for data fetching
34- [ ] Import aliases: `@/`, `~types`, `~components`, `~features`
35- [ ] Styles: Inline if <100 lines, separate file if >100 lines
36- [ ] Use `useCallback` for event handlers passed to children
37- [ ] Default export at bottom
38- [ ] No early returns with loading spinners
39- [ ] Use `useMuiSnackbar` for user notifications

43Creating a feature? Set up this structure:
44

101### 🎨 Component Patterns
102 
103**Modern React components use:**
104- `React.FC<Props>` for type safety
105- `React.lazy()` for code splitting
106- `SuspenseLoader` for loading states
107- Named const + default export pattern
108 
109**Key Concepts:**
110- Lazy load heavy components (DataGrid, charts, editors)
111- Always wrap lazy components in Suspense
112- Use SuspenseLoader component (with fade animation)
113- Component structure: Props → Hooks → Handlers → Render → Export

120 
121**PRIMARY PATTERN: useSuspenseQuery**

204### ⏳ Loading & Error States
205 
206**CRITICAL RULE: No Early Returns**
207 
208```typescript
209// ❌ NEVER - Causes layout shift
210if (isLoading) {
211    return <LoadingSpinner />;
212}
213 
214// ✅ ALWAYS - Consistent layout
215<SuspenseLoader>
216    <Content />
217</SuspenseLoader>
218```
219 
220**Why:** Prevents Cumulative Layout Shift (CLS), better UX
221 
222**Error Handling:**
223- Use `useMuiSnackbar` for user feedback
224- NEVER `react-toastify`
225- TanStack Query `onError` callbacks
