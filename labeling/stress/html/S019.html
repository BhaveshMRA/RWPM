49## 写作规范(产出是文章,不是清单)
50 
51- **一篇文章的结构**:抓人的标题 + 一段开场点题;正文用自然段把当天最重要的几条线索串起来(共同主题、对比、因果);结尾给 AI 开发者
 >一个判断或启示。
52- **不要**用「## Hacker News / ## V2EX」这种按来源切分的小标题堆条目。来源是论据,自然编织进行文。
53- **链接内联**:把可点击链接嵌进正文相关词句(Markdown 内联链接),points/评论数只在能增强说服力时顺带提。
54- 语气像懂行的编辑跟开发者聊今天最该关心的事;紧凑、有节奏、可速读但有深度。
55- **诚实**:`md` 顶部的 gaps 要在行文里一句带过,**绝不编造**(尤其 X 引用)。不为凑长度灌水,也不怕长文。
56- 标题可用 `☕ AI/Tech Morning Digest — <今天日期>`。
57 
58## 时间窗 / 出周报或月报
59 
60只有一个总开关:`output.recencyHours`(默认 36 小时),命令行可临时覆盖 `--days N` 或 `--hours N
 >`。这个数字会同时驱动**每个**来源的时间过滤,以及 Reddit / HN 的「top of day|week|month」选择,所以出周报
 >就是 `node collect.js --days 7`,月报 `--days 30`。具体行为:RSS / arXiv / GitHub r
 >eleases / X / V2EX / Reddit 都按这个窗口截断;Reddit `top` 自动切到对应的 day/week/month
 >;HN 在「首页热门」之外再按日期范围搜过去整段时间;GitHub releases 有 72 小时下限(发布稀疏)。
61 
62## 热门 ≠ 今天创建(trending 语义)
63 
64GitHub trending、Product Hunt、Hugging Face、HN 首页、Reddit top 这些是「现在热」的榜,不代
 >表条目是今天才创建/发布的(一个今天上热榜的 repo 可能是几年前建的)。这些条目会被标 `trending`:**不按创建时间过滤**,排序
 >时把「时效」分中性化、改看热度(stars / 点赞 / 下载)。素材里它们显示成 `🔥 trending`(GitHub 会附 `create
 >d <日期>`),而不是一个会误导的「发布时间」。
65 
66## 是否点进原文读正文(enrichment)
67 
68默认**会**点进排名最高的若干条链接读正文(不是只拿标题列表)。由 `output.enrichTopN`(默认 12)控制条数,只对官方 b
 >log / 研究 / agent 工具 / 发布 / benchmark / PH 这类带正文的外链做,跳过 HN/Reddit/X/V2EX(
 >它们本身已带讨论文本)。读到的正文写进素材的「Full text」段,标 `full text ✓`。设 `--enrich 0` 关闭。注意:
 >开了会更慢,也可能多触发几次人机验证暂停。

70## 配置 sources.json
71

76## 人机验证 / 登录(交互式暂停)
77 
78X 优先走 GraphQL 拦截（CDP Network 层截获 timeline GraphQL 响应，拿结构化 tweet JSON；DOM
 > 为空时回退）。此外，抓 X、V2EX、Reddit、JS 渲染官方页时,若页面弹出 Cloudflare 验证、验证码或登录墙,脚本会**暂停
 >并保留该页面**,在终端提示你去 Chrome 窗口里完成验证,然后回终端按 Enter 继续(验证通过后也会自动继续)。这样就不会像以前那样「
 >等几秒就抓走、直接切下一页」。
79 
80- 仅在**交互式运行**(终端有 TTY)时暂停;**定时/无人值守**运行不会卡住,会把该来源记为 gap 继续。
81- 开关:`sources.json` 的 `output.pauseForVerification`(默认 true)。等待上限用环境变量 `
 >AI_DIGEST_VERIFY_TIMEOUT`(秒,默认 180)。强制无人值守:`AI_DIGEST_NONINTERACTIVE=1`。
82- RSS 那批(~28 个源)不弹暂停,失败就静默回退,避免反复打断。
83- 脚本只读 DOM 文本,**不截图、不做视觉识别**。

85## 故障与回退
86 
87- `Cannot reach Chrome DevTools at :9222` → 先 `node chrome-launch.js`。
88- 某 RSS 403/超时 → 脚本会自动改用浏览器内 fetch(CDP 在线时)。
89- X 没抓到 → 多半是掉登录或限流;交互式会暂停让你登录,无人值守则记为 gap。
90- 单个来源崩溃不会中断整体(每个 collector 独立 settle)。
