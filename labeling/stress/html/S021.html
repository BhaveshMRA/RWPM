102## Gotchas
103 
104- **`use_fast_transformer` default is `True`** but resolves to a FlashAt
>tention 
105  path that may not import in every env. Pass `use_fast_transformer=Fals
>e` 
106  unless you've confirmed `flash_attn` loads cleanly.
107- The package historically depended on `torchtext.vocab.Vocab`; in
108  environments without torchtext a pure-Python shim provides `Vocab` —
109  functionally identical for `GeneVocab`, but if you hit
110  `AttributeError: 'Vocab' object has no attribute …`, you're on a stale
> shim. 
111- Gene names must match the vocab; unmatched genes are dropped. Set
112  `gene_col` to the column in `adata.var` that holds symbols.
