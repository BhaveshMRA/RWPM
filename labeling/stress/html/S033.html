28### Authentication
29 
30Strava uses OAuth2. Generate an auth link, send it to the user, then ask
 > them to paste back the redirect URL.
31 
32**Step 1: Generate auth URL**
33 
34```bash
35set -a; source .env 2>/dev/null; set +a; uv run - <<'EOF'
36# /// script
37# requires-python = ">=3.11"
38# dependencies = ["stravalib>=2.4"]
39# ///
40import os
41from stravalib import Client
42 
43client = Client()
44url = client.authorization_url(
45    client_id=int(os.environ["STRAVA_CLIENT_ID"]),
46    redirect_uri="http://localhost/callback",
47    scope=["read", "activity:read", "activity:read_all", "profile:read_a
 >ll"]
48)
49print(f"URL: {url}")
50EOF
51```
52 
53Send the URL to the user as a clickable link. Tell them:
54 
551. Click the link and authorize the app
562. The browser will redirect to a page that won't load (localhost) — **t
 >hat's expected**

 >here

59**Step 2: Exchange code for tokens** (after user pastes the redirect URL

200## Guidelines
201 
2021. **Token expiry**: Access tokens expire every 6 hours — the platform h
>andles refresh automatically via the connector 
2032. **Pagination**: Use `page` and `per_page` (max 200) for list endpoint
>s 
2043. **Time filters**: Use Unix epoch timestamps for `before`/`after` para
>meters 
2054. **Scope requirements**: Ensure token has correct scopes; `activity:re
>ad_all` needed for private activities, `activity:write` needed to create 
>/edit 
2065. **Rate limits**: 200 req/15min, 2000 req/day — add delays for bulk op
