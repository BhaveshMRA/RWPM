49 
50### Browser Lifecycle
51 
52Rod manages three layers: **Browser → Page → Element**.
53 
54```go
55// Launch and connect to a browser
56browser := rod.New().MustConnect()
57defer browser.MustClose()
58 
59// Create a page (tab)
60page := browser.MustPage("https://example.com")
61 
62// Find an element
63el := page.MustElement("h1")
64fmt.Println(el.MustText())
65```
66 
67### Must vs Error Patterns
68 
69Rod provides two API styles for every operation:
70 
71| Style | Method | Use Case |
72|:------|:-------|:---------|
73| **Must** | `MustElement()`, `MustClick()`, `MustText()` | Scripting, d
>ebugging, prototyping. Panics on error. | 
74| **Error** | `Element()`, `Click()`, `Text()` | Production code. Return
>s `error` for explicit handling. | 
75 
76**Production pattern:**
77 
78```go
79el, err := page.Element("#login-btn")
80if err != nil {
81    return fmt.Errorf("login button not found: %w", err)
82}
83if err := el.Click(proto.InputMouseButtonLeft, 1); err != nil {
84    return fmt.Errorf("click failed: %w", err)
85}
86```
87 
88**Scripting pattern with Try:**
89 
90```go
91err := rod.Try(func() {
92    page.MustElement("#login-btn").MustClick()
93})
94if errors.Is(err, context.DeadlineExceeded) {
95    log.Println("timeout finding login button")
96}
97```
98 
99### Context & Timeout
100 
101Rod uses Go's `context.Context` for cancellation and timeouts. Context p
>ropagates recursively to all child operations. 
102 
103```go
104// Set a 5-second timeout for the entire operation chain
105page.Timeout(5 * time.Second).
106    MustWaitLoad().
107    MustElement("title").
108    CancelTimeout(). // subsequent calls are not bound by the 5s timeout
109    Timeout(30 * time.Second).
110    MustText()
111```

131### Auto-Wait
132 
133Rod automatically retries element queries until the element appears or t
>he context times out. You do not need manual sleeps: 
134 
135```go
136// This will automatically wait until the element exists
137el := page.MustElement("#dynamic-content")
138 
139// Wait until the element is stable (position/size not changing)
140el.MustWaitStable().MustClick()
141 
142// Wait until page has no pending network requests
143wait := page.MustWaitRequestIdle()
144page.MustElement("#search").MustInput("query")
145wait()

150## Stealth & Anti-Bot Detection (go-rod/stealth)
151 
152> **IMPORTANT:** For any production scraping or automation against real 
>websites, ALWAYS use `stealth.MustPage()` instead of `browser.MustPage() 
>`. This is the single most important step for avoiding bot detection. 
153 
154### How Stealth Works
155 
156The `go-rod/stealth` package injects JavaScript evasions into every new 
>page that: 
157 
158- **Remove `navigator.webdriver`** — the primary headless detection sign
>al. 
159- **Spoof WebGL vendor/renderer** — presents real GPU info (e.g., "Intel
> Inc." / "Intel Iris OpenGL Engine") instead of headless markers like "G 
>oogle SwiftShader". 
160- **Fix Chrome plugin array** — reports proper `PluginArray` type with r
>ealistic plugin count. 
161- **Patch permissions API** — returns `"prompt"` instead of bot-revealin
>g values. 
162- **Set realistic languages** — reports `en-US,en` instead of empty arra
>ys. 
163- **Fix broken image dimensions** — headless browsers report 0x0; stealt
>h fixes this to 16x16. 
164

166

486## Best Practices
487 
488- ✅ **ALWAYS use `stealth.MustPage(browser)`** instead of `browser.MustP
>age()` for real-world sites. 
489- ✅ **ALWAYS `defer browser.MustClose()`** immediately after connecting.
490- ✅ Use the error-returning API (not `Must*`) in production code.
491- ✅ Set explicit timeouts with `.Timeout()` — never rely on defaults for
> production. 
492- ✅ Use `browser.MustIncognito().MustPage()` for isolated sessions.
493- ✅ Use `PagePool` for concurrent scraping instead of spawning unlimited
> pages. 
494- ✅ Use `MustWaitStable()` before clicking elements that might be animat
>ing. 
495- ✅ Use `MustWaitRequestIdle()` after actions that trigger AJAX calls.
496- ✅ Use `launcher.New().Headless(false).Devtools(true)` for debugging.
497- ❌ **NEVER** use `time.Sleep()` for waiting — use Rod's built-in wait m
>ethods. 
498- ❌ **NEVER** create a new `Browser` per task — create one Browser, use 
>multiple `Page` instances. 
499- ❌ **NEVER** use `browser.MustPage()` for production scraping — use `st
>ealth.MustPage()`. 
500- ❌ **NEVER** ignore errors in production — always handle them explicitl
>y. 
501- ❌ **NEVER** forget to defer-close browsers, pages, and hijack routers.
502 
503## Common Pitfalls
504 
505- **Problem:** Element not found even though it exists on the page.
506  **Solution:** The element may be inside an iframe or shadow DOM. Use `
>page.MustSearch()` instead of `page.MustElement()` — it searches across  
>all iframes and shadow DOMs. 
507 
508- **Problem:** Click doesn't work because the element is animating.
509  **Solution:** Call `el.MustWaitStable()` before `el.MustClick()`.
510
