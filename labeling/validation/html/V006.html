236## Anti-Patterns to Avoid
237 
238### ❌ God Agent
239One agent that does everything - no specialization, no delegation.
240 
241### ❌ Agent Explosion
242Too many tiny agents with overlapping responsibilities.
243 
244### ❌ Lost Context
245Handoffs that don't preserve essential information.
246 
247### ❌ Infinite Loops
248Agents that keep handing work back and forth.
249 
250### ❌ Silent Failures
251Agents that fail without proper error reporting.
252 
253### ❌ Unobservable Execution
254Can't see what agents are doing or why.
