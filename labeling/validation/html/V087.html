113## Forms
114 
115Good form design dramatically reduces abandonment:
116 
117- **Label every field** — always above the input, never placeholder-only
 >.
118- **Inline validation on blur**, not only on submit. Show success state 
 >(`✓`) for completed fields.
119- **Error messages:** specific ("Password must be at least 8 characters"
 >) not generic ("Invalid input").
120- **Group related fields** visually (address block, card details).
121- Error recovery: **preserve user input** — never clear a form on error.
122- `type="email"`, `type="tel"`, `type="number"` — use correct types for 
 >mobile keyboard optimization.
123- Autofocus the first field in isolated flows (login, modal forms).
124- Required fields: mark optional ones (`optional`) rather than every req
 >uired one with `*`.

153

 >le scroll) — never the only way to perform an action.
