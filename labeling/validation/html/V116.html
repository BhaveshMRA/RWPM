75> **Heads up on the alias syntax.** Pre-v1.2.0 docs used a
76> `[accounts.NAME.folder.alias]` sub-section (singular `alias`).
77> v1.2.0 silently ignores that form — TOML parses fine, but the
78> alias resolver never reads it, so every lookup falls through to
79> the canonical name. On Gmail this means save-to-Sent fails *after*
80> SMTP delivery succeeds, and `himalaya message send` exits non-zero.
81> Any caller (agent, script, user) that retries on that exit code
82> will re-run the entire send — including SMTP — producing duplicate
83> emails to recipients. Always use `folder.aliases.X` (plural, dotted
84> keys, directly under `[accounts.NAME]`).
